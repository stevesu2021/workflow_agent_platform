“智能体”页面，在构建workflow智能体画布的“规划”页面，添加“代码块”节点。

以下是对 “代码块节点（Code Block Node）” 的完整需求文档，专为可视化 Workflow 系统设计，强调安全性、可维护性与开发体验一致性。

代码块节点（Code Block Node）需求文档

一、目标

提供一个内嵌 Python 脚本执行能力的节点，允许用户在 Workflow 中编写轻量级数据处理逻辑。该节点需满足以下核心原则：

- 输入统一：所有外部变量通过 params 字典传入；
- 输出规范：处理结果必须写入 output 字典；
- 安全隔离：禁止访问系统资源、文件、网络等危险操作；
- 可观测性：支持日志输出与错误定位；
- 无状态执行：每次调用独立，不依赖全局状态。

二、功能规格

1. 输入（Input）

- 所有上游传递的变量自动注入到一个名为 params 的字典中。
  - 例如：若上游节点输出了 user_id 和 scores，则：
        params = {
        "user_id": "U12345",
        "scores": [85, 92, 78]
    }
    

- 用户不能直接引用 {{vars.xxx}} 等模板变量，所有数据必须通过 params 访问。

2. 用户代码区域（User Code）

- 提供一个文本编辑器（支持语法高亮），用户在此编写 Python 代码片段。
- 代码必须遵循以下结构约束：
  - 可自由定义函数、中间变量、控制流（if/for 等）；
  - 必须在末尾将结果写入一个名为 output 的字典；
  - 不得包含 import（除白名单模块外）、exec、eval、open、os、sys 等危险语句。

✅ 合法示例：
计算平均分并判断是否及格
total = sum(params["scores"])
avg = total / len(params["scores"])
is_pass = avg >= 60

output = {
    "average_score": avg,
    "is_pass": is_pass,
    "message": f"Hello {params['user_id']}, your average is {avg:.2f}"
}

❌ 非法示例（应被拦截）：
import os  # ❌ 禁止 import
print(open("/etc/passwd").read())  # ❌ 危险操作
exec("...")  # ❌ 动态执行

3. 输出（Output）

- 节点执行成功后，output 字典中的所有键值对将作为该节点的输出变量，供下游节点使用。
  - 例如上述示例将输出三个变量：average_score、is_pass、message
- 若用户未定义 output 或 output 非 dict 类型，则抛出运行时错误。

4. 白名单内置模块（可选增强）

为提升实用性，可预加载以下只读、无副作用的标准库模块（通过受限执行环境实现）：

- math
- datetime（仅构造和格式化，禁用 .now() 等非确定性函数）
- json
- re
- collections（如 Counter, defaultdict）

注：是否启用白名单模块由系统策略决定，初期可关闭以简化安全模型。

三、UI/UX 需求
元素   说明
节点图标   显示  或 Python 标志

节点名称   默认 “Python 代码块”，可编辑

代码编辑区   多行文本框，支持 Python 语法高亮（如 Monaco Editor）

帮助提示   在编辑器上方显示：# 请通过 params 获取输入，结果请赋值给 output（dict）

错误反馈   执行失败时，在节点下方显示红色错误信息（如 “NameError: name 'output' is not defined”）

只读模式   在流程预览或运行时，代码区域置灰不可编辑

四、执行引擎要求

安全执行沙箱（关键！）

- 使用 受限执行环境（如 RestrictedPython、Pyodide 子集、或自定义 AST 检查）运行用户代码。
- 禁止以下行为：
  - 文件 I/O
  - 网络请求
  - 进程/线程创建
  - 访问 builtins 危险函数
  - 修改全局状态
- 设置执行超时（如 5 秒）和内存限制。

上下文注入

执行前构建安全上下文：
safe_globals = {
    "builtins": safe_builtins,  # 仅保留 print, len, str, int, float, list, dict 等
    "params": input_params,         # 来自上游的变量字典
    "output": None                  # 初始化
}

exec(user_code, safe_globals)

执行后提取 output
result_output = safe_globals.get("output")
if not isinstance(result_output, dict):
    raise RuntimeError("output must be a dictionary")

五、错误处理
错误类型   处理方式
语法错误   捕获 SyntaxError，提示行号

运行时异常   捕获异常，显示完整 traceback（脱敏后）

未定义 output   明确报错：“请确保代码末尾定义 output = {...}”

超时/资源超限   终止执行，标记节点失败

六、使用场景示例

1. 数据清洗：过滤无效值、标准化格式  
2. 简单计算：求和、平均、排名  
3. 条件构造：根据多字段生成复合标签  
4. 格式转换：将列表转为字符串、JSON 序列化等  

七、后续扩展建议

- 支持 TypeScript/JavaScript 代码块（多语言）
- 提供常用函数模板库（如 utils.round(x, 2)）
- 允许用户保存常用代码片段为“自定义函数节点”

通过此设计，代码块节点既能满足灵活的数据处理需求，又能保障 Workflow 系统的安全性与稳定性，适合作为低代码平台中的“高级扩展”能力。
